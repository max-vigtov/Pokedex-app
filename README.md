# Pokedex App

A modern and feature-rich Pokémon encyclopedia built with React Native. This application provides a comprehensive interface for exploring and learning about Pokémon, leveraging the latest mobile development technologies and best practices.

## 🚀 Features

- Clean Architecture implementation (Domain, Infrastructure, Presentation layers)
- Modern UI/UX with React Native Paper components
- Efficient state management with React Query
- Smooth navigation using React Navigation
- Type-safe development with TypeScript
- Responsive design for both iOS and Android platforms

## 🛠️ Tech Stack

- React Native 0.75.2
- TypeScript
- React Query for data fetching and caching
- React Navigation for routing
- React Native Paper for UI components
- Axios for API requests
- ESLint & Prettier for code quality

## 📱 Requirements

- Node.js >= 18
- Yarn 3.6.4
- iOS/Android development environment

## 🏗️ Project Structure

The project follows a clean architecture pattern with the following structure:
- `src/domain/` - Business logic and entities
- `src/infrastructure/` - External services and implementations
- `src/presentation/` - UI components and screens
- `src/actions/` - Application actions and state management
- `src/config/` - Configuration files
- `src/assets/` - Static assets and resources

## 🚀 Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   yarn install
   ```
3. Start the development server:
   ```bash
   yarn start
   ```
4. Run on iOS:
   ```bash
   yarn ios
   ```
   or Android:
   ```bash
   yarn android
   ```
